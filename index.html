WordMapper

Five words name any point on earth to about a metre.

Try it

  • The global grid — click anywhere and get a stable five-word address.
  • Shortening by country — a country bounding box may supply the leading word, making four words possible.

How it works

The grid is global and runs entirely in JavaScript. A coordinate is encoded immediately, without a network request or external boundary data. The fifth word also carries a checksum.

The shortening demo uses OpenStreetMap only as a search window. If that window is too large, ambiguous, unavailable, or changes over time, the safe five-word address is retained.
